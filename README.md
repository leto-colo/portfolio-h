# 🚀 LiTianHao 个人作品集 - Cursor 启动指南> 这份指南帮你在 5 分钟内,把网站在 Cursor 里跑起来。\---## 📦 你拿到了什么这个文件夹里有两个文件:```portfolio-honest/├── index.html      ← 你的整个网站(单文件)└── README.md       ← 这个指南```\*\*就这么简单。\*\*所有 HTML、CSS、JS、动画、交互全部在 `index.html` 一个文件里,改它就够了。\---## 🎯 5 分钟跑起来### Step 1: 在 Cursor 里打开这个文件夹1. 打开 Cursor2. 顶部菜单 **File → Open Folder**3. 选择 `portfolio-honest` 这个文件夹4. 你会在左侧文件树看到 `index.html`\---### Step 2: 安装 Live Preview 扩展(只需一次)1. 点 Cursor 左侧栏最下面那个**四个方块**的图标(Extensions)2. 顶部搜索框输入 `Live Preview`3. 找到 **Microsoft 出的 Live Preview**(看图标是个浏览器加播放符号)4. 点 **Install**\---### Step 3: 预览网站1. 在左侧文件树,**右键** `index.html`2. 选 **Show Preview**(或 Open with Live Preview)3. ✨ Cursor 会在右半边打开一个内置浏览器,显示你的网站> 💡 想在外部浏览器看(更真实):右键 → \\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\*\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\*Show Preview (External Browser)\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\*\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\*,会用 Chrome / Edge 打开,效果更好,移动端测试也更方便。\---## ✏️ 怎么改东西### 改文字(最简单)直接在 `index.html` 里**用 Ctrl+F 搜索**你想改的文字,改完 **Ctrl+S 保存**,Live Preview 自动刷新。**常用搜索关键词:**|你想改|搜这个关键词||-|-||Hero 标题"正在成为一个能交付的 AI 训练师"|`能交付的`||Hero 数据卡片(12 / 6 / 4)|`Bad Cases<br>已分析`||邮箱|`ltianhao310`||城市|`杭州`||About 模块文案|`我还在想怎么介绍自己`||Project A 标题|`中文长文本摘要`||Manifesto 5 条信念|`训练 AI 的本质`|\---### 改颜色整个网站只有 3 个核心颜色,全局搜索替换即可:|颜色|含义|当前值||-|-|-||`#0E0E0C`|背景色(深空黑)|主背景||`#E8E6E0`|主文字色(米白)|文字||`#D97757`|强调色(Anthropic 暖橙)|高亮、按钮、动画|**操作**:Ctrl+H 打开"查找替换",输入旧值和新值,点 Replace All。\---### 加一篇 Bad Case 文章(暂不需要文章详情页)现阶段 Bad Case 列表是占位的"假文章",你点上去不会跳转。这是有意为之——**先把骨架立住**,后续真有文章了再升级到 Next.js。\---## ⚠️ 现阶段还做不了什么这一版是**单 HTML 文件**,有 3 个限制:1. **Bad Case 文章点击不会跳转**——因为还没有详情页2. **不能写 Markdown 自动变成网页**——需要升级到 Next.js3. **没有 SEO 预览图**——HR 把链接发到飞书,不会显示漂亮缩略图这 3 件事,等你**对内容打磨满意 + 想正式部署给 HR 看**的时候,我们再升级。**现在的版本足够你给朋友看、给自己迭代用了**。\---## 🌐 想让别人也能看?(2 分钟部署到 Vercel)> 这一步现在不急,等你对内容满意了再做。**最简方案**(不用 Git,适合不熟代码的人):1. 注册 [https://vercel.com](https://vercel.com)(用 GitHub 登录最方便)2. 进 dashboard,点 **Add New → Project**3. 选 **"Import Third-Party Git Repository"** 旁边那个
